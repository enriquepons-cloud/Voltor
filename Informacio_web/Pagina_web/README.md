# Web de Voltor

Web en español hecha con HTML, CSS y JavaScript, sin dependencias.

## Abrir

Abre `index.html` en un navegador. No necesita instalación ni servidor.

## Añadir el juego

En `script.js`, cambia `const GAME_URL = "";` por el enlace real del juego, por ejemplo:

```js
const GAME_URL = "https://tu-dominio.com/juego";
```

El apartado «Jugar» sustituirá automáticamente «Próximamente» por un enlace que abre el juego en una nueva pestaña. Hasta entonces no muestra un enlace ficticio.

## Modificar la información

- `index.html`: textos, secciones y controles.
- `styles.css`: colores, tipografía y adaptación a móvil.
- `script.js`: menú móvil y enlace del juego.
- `assets/voltor-referencia.png`: imagen incluida en la presentación, mostrada como referencia visual y no como captura verificada del juego.

Contenido traducido del PowerPoint `voltor_JalaiHazi_QuiquePons_EricDiaz.pptx`. Autores indicados en la portada: Jalail Hazi, Quique Pons y Eric Diaz. La web presenta el proyecto; el juego se enlazará cuando esté disponible.
